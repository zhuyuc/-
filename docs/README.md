# 模拟交易台

本地运行的 A 股、港股模拟交易记录工具。A 股固定使用 CNY，港股固定使用 HKD；交易数据按本地账号隔离保存。

## 目录结构

文档统一放在 `docs/`，代码与数据的放置规则见 [STRUCTURE.md](STRUCTURE.md)。启动与测试命令均在项目根目录执行。

## 启动

在项目目录执行：

```powershell
python app.py
```

浏览器打开 <http://127.0.0.1:8765/>。

股票搜索优先使用当前账号的本地名录；本地没有匹配时，会从公开证券目录补全 A 股和港股普通股票，并把结果写入当前账号的 SQLite 缓存。外部目录不可用时仍可搜索已缓存的股票。行情在登录和点击「更新数据」时从腾讯行情接口拉取持仓股票的最新价并写入本地；外部行情不可用时回退到本地保存的最后价格（含成交价推导），浮动盈亏按最后保存价格计算。

## 回归测试

```powershell
python -m unittest discover -s tests -v
node --check static/app.js
python -m py_compile app.py
```

测试覆盖本地账号隔离、CNY/HKD 自动币种、证券搜索、交易费用、卖出数量校验、移动加权平均与 FIFO、静态页面和费用接口。
